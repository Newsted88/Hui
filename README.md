# Вивчаємо Python з нуля

Це послідовний практичний курс для людини, яка ще не програмувала. Мета — самостійно писати невеликі програми та розуміти функції. Потрібні Windows, Visual Studio Code (VS Code) і Python 3.12 або новіший. Уроки йдуть від 00 до 11; кожен спирається на попередній. Зовнішні бібліотеки й команда `pip` не потрібні.

## Підготовка Windows

1. Завантажте Python з [офіційного сайту](https://www.python.org/downloads/). Під час встановлення позначте **Add python.exe to PATH**, якщо така опція є.
2. Відкрийте PowerShell і введіть `py --version`. Має з’явитися версія 3.12 або новіша. Якщо `py` недоступна, спробуйте `python --version`. Якщо Windows пропонує Microsoft Store замість Python, встановіть Python з офіційного сайту та відкрийте новий термінал.
3. Встановіть [VS Code](https://code.visualstudio.com/) і розширення **Python** від Microsoft у вкладці Extensions.
4. У VS Code виберіть **File → Open Folder** і відкрийте папку цього курсу. Якщо VS Code просить вибрати інтерпретатор, натисніть **Python: Select Interpreter** і виберіть встановлений Python 3.12+.
5. Виберіть **Terminal → New Terminal**. Переконайтеся, що термінал відкритий у папці курсу: `Get-Location`.

## Перша програма

Відкрийте `lessons/00_getting_started/examples.py`. Спробуйте передбачити результат, а тоді в інтегрованому PowerShell виконайте:

```powershell
py .\lessons\00_getting_started\examples.py
```

Якщо працює лише команда `python`, замініть `py` на `python`. Інші файли запускаються так само: `py .\lessons\01_print_and_comments\examples.py`. Збережіть зміни (`Ctrl+S`) перед запуском.

## Як проходити курс

У кожній папці уроку є `README.md` (пояснення), `examples.py` (готові приклади з коментарями), `exercises.py` (ваші завдання), `hints.md` (три послідовні підказки до кожного завдання) та `quiz.md` (запитання для перевірки). Читайте уроки по порядку. Мініпроєкт 1 виконуйте після уроку 03, мініпроєкт 2 — після 10, мініпроєкт 3 — після 11. Їхні файли лежать у `mini_projects`.

У `exercises.py` знайдіть позначки `TODO`, напишіть свій код під відповідними коментарями та запустіть файл. Порожній файл вправ нічого не виводить — це нормально. Для завдань із введенням даних перевірте кілька значень. Не копіюйте приклад без розуміння; поясніть собі, що робить кожен рядок. Позначайте пройдене у [PROGRESS.md](PROGRESS.md).

Якщо застрягли, відкрийте лише підказку 1 до потрібної вправи, спробуйте ще раз, потім перейдіть до підказок 2 і 3. Готових відповідей тут немає. AI-викладачеві покажіть власний код і конкретну помилку; попросіть запитання або невелику підказку та перевірку вашого пояснення. Інструкції для такого викладача є у [AGENTS.md](AGENTS.md).

## Ритм одного заняття

1. Прочитайте теорію.
2. Розгляньте приклад і його коментарі.
3. Передбачте результат запуску.
4. Запустіть приклад.
5. Виконайте вправу самостійно.
6. Попросіть AI-викладача переглянути ваш код.
7. Виправте помилки й поясніть причину виправлення.
8. Рухайтеся далі, коли зрозумієте тему.

## Коли щось не працює

Перевірте, чи збережено файл, чи термінал відкритий у папці курсу і чи шлях до файлу написаний без помилки. Прочитайте **останній рядок** повідомлення про помилку: там часто вказано тип проблеми. Зверніть увагу на лапки, двокрапку та відступи. Для вправ із `input()` вводьте дані у терміналі й натискайте Enter. Якщо все ще складно, покажіть AI-викладачеві команду запуску, текст помилки і кілька рядків свого коду. Не надсилайте паролі чи особисті дані.
