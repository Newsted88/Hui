# Урок 03. Введення даних

## Мета уроку

- отримувати текст через `input()`
- перетворювати його на `int` і `float`
- створити короткий діалог із користувачем

## Перед початком

Урок 02: змінні та типи.

## Пояснення

`input("Запитання: ")` показує запитання й чекає, доки людина введе відповідь у терміналі та натисне Enter. Результат завжди має тип `str`, навіть якщо введено цифри. Збережіть його у змінній, щоб використати пізніше.

Для цілого числа використовуйте `int(текст)`, для дробового — `float(текст)`. Наприклад, `age = int(input("Вік: "))`. Python спочатку виконує внутрішній `input`, потім перетворює його результат через `int`, потім присвоює змінній `age`.

Якщо ввести `два` замість `2`, `int()` не зможе виконати перетворення і покаже `ValueError`. Для дробового числа вводьте крапку: `2.5`. Поки що вводьте дані того виду, якого просить програма; обробку неправильних відповідей розглянемо на практиці пізніше.

Спілкування програми з людиною складається з підказки, введення, обробки й результату. Добре запитання пояснює, що саме вводити.


## Приклад із поясненням

```python
name = input("Як вас звати? ")
print("Вітаю, " + name)
```

Програма зупиниться й чекатиме ім'я. Після Enter покаже привітання з введеним текстом. У [examples.py](examples.py) є додаткові коментарі до кожного нового кроку.

## Поширені помилки

- `input()` повертає текст: `"2"` і `"3"` не стають числами самі.
- Для дробового числа використовуйте крапку, а не кому.
- Якщо термінал здається «завислим», подивіться, чи програма чекає вашого введення.
