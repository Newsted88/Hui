# Урок 08. Цикл while

## Мета уроку

- пояснити, навіщо повторювати дії
- керувати лічильником у `while`
- розуміти `break`, `continue` та ризик нескінченного циклу

## Перед початком

Урок 07: умови й відступи.

## Пояснення

Цикл повторює блок коду. `while умова:` означає: перевір умову; якщо вона істинна, виконай блок і знову перевір. Коли умова стає хибною, Python продовжує після циклу. Це корисно, коли кількість повторів наперед невідома.

Лічильник — змінна для відстеження повторів. У `count = 1; while count <= 3:` обов'язково змінюйте `count` усередині циклу, наприклад `count = count + 1`. Інакше умова може залишатися істинною завжди, і виникне нескінченний цикл. У терміналі його можна зупинити `Ctrl+C`.

`break` одразу виходить із найближчого циклу. `continue` пропускає решту поточного повтору й повертається до перевірки умови. Перед `continue` у циклі з лічильником оновіть лічильник, інакше легко застрягнути на одному значенні.

Перед запуском запитайте себе: яке значення змінюється на кожному повторі та коли умова стане хибною? Це найкращий спосіб перевірити цикл.


## Приклад із поясненням

```python
count = 1
while count <= 3:
    print(count)
    count = count + 1
```

З'являться 1, 2, 3. Після третього показу `count` стане 4, тому перевірка буде хибною. У [examples.py](examples.py) є додаткові коментарі до кожного нового кроку.

## Поширені помилки

- Лічильник не змінюється, тож цикл не закінчується.
- `continue` стоїть перед оновленням лічильника.
- Відступивши не той рядок, можна винести зміну лічильника за цикл.
