# Урок 10. Списки

## Мета уроку

- створювати список і діставати елементи
- додавати й видаляти значення
- проходити список циклом і рахувати його довжину

## Перед початком

Урок 09: `for`, рядки та індекси.

## Пояснення

Список зберігає кілька значень в одному місці, як список покупок. Запис `items = ["хліб", "молоко"]` створює два елементи. Елементи відділені комами. На відміну від рядка, список можна змінювати після створення.

Як і в рядку, індекси починаються з нуля. `items[0]` — перший елемент, `items[-1]` — останній. `len(items)` рахує елементи, а не символи. Звернення до неіснуючого індексу спричиняє `IndexError`.

`items.append("чай")` додає значення в кінець списку. `items.remove("хліб")` видаляє перший елемент із таким значенням. Якщо значення немає, `remove()` спричинить `ValueError`. Ці методи змінюють сам список.

Цикл `for item in items:` по черзі дає кожен елемент. Це простіше, ніж вручну звертатися до кожного індексу. Якщо список порожній, тіло циклу не виконається.


## Приклад із поясненням

```python
items = ["хліб", "молоко"]
items.append("чай")
for item in items:
    print(item)
```

Будуть показані хліб, молоко, чай — у порядку елементів списку. У [examples.py](examples.py) є додаткові коментарі до кожного нового кроку.

## Поширені помилки

- `len(items)` рахує елементи, а не літери.
- Перший індекс — 0.
- `remove()` шукає значення, а не номер.
- `append()` змінює список; його результат не треба присвоювати назад.
