## Пояснення

Рядок (`str`) — послідовність символів: літер, цифр, пробілів. Оператор `+` поєднує два рядки: `"Добрий " + "день"`. Він не вставляє пробіл самостійно. `len(text)` рахує всі символи, включно з пробілами.

Кожен символ має номер — індекс. Python починає нумерацію з нуля: у `"кіт"` символ `text[0]` — `к`, `text[1]` — `і`. Останній символ можна взяти як `text[-1]`. Якщо такого номера немає, буде `IndexError`. Для порожнього рядка немає першого символу.

Метод — готова дія, прив'язана до значення. `text.upper()` повертає великі літери, `text.lower()` — малі, `text.strip()` прибирає пробіли на краях. Вони повертають новий рядок; початковий рядок не змінюється, якщо результат не присвоїти змінній.

f-рядок дозволяє вставити значення всередину тексту: `f"Привіт, {name}!"`. Літера `f` стоїть перед лапками, а ім'я змінної — у фігурних дужках. Це зручно і для чисел, бо їх не треба вручну перетворювати на текст.


## Приклад із поясненням

```python
name = "Оля"
print(f"Привіт, {name}!")
print(len(name))
```

З'являться `Привіт, Оля!` та 3 — довжина імені. У [examples.py](examples.py) є додаткові коментарі до кожного нового кроку.

## Поширені помилки

- `"Привіт" + 3` спричинить помилку типів; використайте f-рядок.
- Перший індекс — 0, а не 1.
- `upper()` повертає новий рядок; старий не змінюється автоматично.
