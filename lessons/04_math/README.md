# Урок 04. Математичні дії

## Мета уроку

- виконувати основні арифметичні дії
- розрізняти `/`, `//`, `%`, `**`
- пояснювати порядок дій і типові помилки

## Перед початком

Урок 03: числа, змінні й введення.

## Пояснення

Python може рахувати як калькулятор: `+` додає, `-` віднімає, `*` множить, `/` ділить. Звичайне ділення `/` дає число з дробовою частиною типу `float`, навіть якщо результат цілий. Дії з числовими змінними працюють так само.

`//` дає цілу частину ділення, `%` — остачу, `**` підносить до степеня. Наприклад, 8 предметів у пакунках по 3: `8 // 3` дає 2 повні пакунки, `8 % 3` дає 2 предмети, що лишилися. Для від'ємних чисел результат `//` може здивувати: він округлює вниз; поки вправляйтеся з додатними.

Порядок дій: спершу дужки, потім степінь, потім множення й ділення, потім додавання й віднімання. Дії одного рівня здебільшого йдуть зліва направо. Дужки роблять намір явним: `(2 + 3) * 4` відрізняється від `2 + 3 * 4`.

Ділити на нуль не можна: виникне `ZeroDivisionError`. Якщо числові дані прийшли з `input()`, спочатку перетворіть текст на число.


## Приклад із поясненням

```python
apples = 8
print(apples // 3)
print(apples % 3)
```

Результат: 2 повні групи та 2 яблука, що залишилися. У [examples.py](examples.py) є додаткові коментарі до кожного нового кроку.

## Поширені помилки

- `/` і `//` дають різні результати.
- `^` не означає піднесення до степеня; використовуйте `**`.
- Текст із `input()` не є числом без перетворення.
- Ділення на нуль викликає помилку.
