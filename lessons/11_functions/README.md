## Пояснення

Функція — названа частина програми, яку можна викликати багато разів. `def greet():` створює функцію; рядки з відступом — її тіло. Саме визначення не виконує тіло. Лише виклик `greet()` переносить виконання до тіла, а потім Python повертається до рядка після виклику. Це допомагає не повторювати той самий код.

Параметр — ім'я всередині визначення функції, наприклад `name` у `def greet(name):`. Аргумент — конкретне значення під час виклику: `greet("Оля")`. У момент виклику Python присвоює аргумент параметру; тіло використовує це значення.

`print()` лише показує інформацію людині. `return` віддає значення назад туди, де функцію викликали. Наприклад, `result = add(2, 3)` може зберегти повернене число, щоб використати його далі. Якщо функція лише друкує, змінна `result` отримає `None` — спеціальне значення «результату немає». Після `return` виконання цієї функції завершується.

Змінна, створена всередині функції, є локальною: її можна використовувати там, але не поза функцією. Це допомагає різним викликам не заважати один одному. Спершу продумайте вхідні значення, потім дію, потім результат, який функція має повернути.


## Приклад із поясненням

```python
def double(number):
    result = number * 2
    return result

answer = double(4)
print(answer)
```

Python спершу запам'ятовує визначення. Під час `double(4)` параметр `number` стає 4, локальний `result` стає 8, `return` віддає 8 у `answer`; останній рядок показує 8. У [examples.py](examples.py) є додаткові коментарі до кожного нового кроку.

## Поширені помилки

- Визначення `def` саме по собі нічого не показує: потрібен виклик.
- `print()` не замінює `return`, коли число треба використати далі.
- Локальна змінна зазвичай недоступна після завершення функції.
- Не плутайте ім'я параметра у визначенні зі значенням аргументу у виклику.
