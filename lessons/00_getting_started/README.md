# Урок 00. Перший запуск

## Мета уроку

- пояснити своїми словами, що таке програма, Python і код
- запустити файл у VS Code через термінал
- знайти корисний рядок у повідомленні про помилку

## Перед початком

Жодних знань з програмування. Потрібні встановлені Python 3.12+ та VS Code.

## Пояснення

Програма — це послідовність інструкцій для комп'ютера. Наприклад, рецепт пояснює людині, що робити по черзі; програма так само описує кроки для комп'ютера. Код — це текст цих інструкцій. Python — мова, правила якої визначають, як записувати інструкції.

Python читає файл зверху вниз. Коли він доходить до інструкції `print(...)`, показує вказане значення у терміналі. Термінал — вікно для команд і результатів. Файл з кодом має закінчення `.py`. Порядок рядків має значення: спочатку виконується верхній рядок.

Встановіть Python з python.org, вибравши додавання до PATH, якщо інсталятор пропонує. У PowerShell перевірте `py --version` або `python --version`. У VS Code відкрийте папку курсу через File → Open Folder, установіть розширення Python від Microsoft і відкрийте Terminal → New Terminal. Збережіть файл перед запуском.

Помилка — це повідомлення, що Python не зміг виконати інструкцію. `SyntaxError` часто означає порушене правило запису, наприклад пропущену лапку. `NameError` означає, що використано невідоме ім'я. Читайте останній рядок помилки і номер рядка, а потім перевіряйте саме цей фрагмент.


## Приклад із поясненням

```python
print("Привіт!")
print("Я вивчаю Python")
```

Перший рядок показує `Привіт!`, другий — `Я вивчаю Python`. Python виконує їх у такому порядку. У [examples.py](examples.py) є додаткові коментарі до кожного нового кроку.

## Поширені помилки

- Файл не збережено: натисніть Ctrl+S.
- Команду введено не в папці курсу: перевірте `Get-Location`.
- Пропущено лапку або дужку: уважно порівняйте відкриття і закриття.

## Запуск у VS Code

Відкрийте папку курсу у VS Code, збережіть файл і відкрийте **Terminal → New Terminal**. У PowerShell, перебуваючи в корені курсу, введіть `py .\lessons\00_getting_started\examples.py`. Якщо команда `py` не працює, використайте `python` замість неї. Для [exercises.py](exercises.py) замініть ім'я файлу в команді. Урок 03 чекає на введення у терміналі; натисніть Enter після кожної відповіді.
