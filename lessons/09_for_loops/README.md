# Урок 09. Цикл for

## Мета уроку

- повторювати дії за допомогою `for` і `range()`
- проходити символи рядка
- обирати між `for` та `while`

## Перед початком

Урок 08: цикли, умови й відступи.

## Пояснення

`for` послідовно бере елементи з набору значень. `for number in range(3):` дає `number` значення 0, 1, 2. `range(3)` не включає число 3. Це зручно, коли кількість повторів відома.

`range(початок, кінець)` починає з першого числа й зупиняється перед другим. `range(1, 4)` дає 1, 2, 3. Третій аргумент — крок: `range(2, 7, 2)` дає 2, 4, 6. Відступ позначає тіло циклу.

Рядок теж є послідовністю символів. `for letter in "кіт":` по черзі бере `к`, `і`, `т`. Ім'я `letter` — змінна для поточного символу. `for` сам переходить до наступного елемента; не треба вручну збільшувати лічильник.

Коли відома кількість повторів або є послідовність — зазвичай зручний `for`. Коли повторення має тривати до виконання умови, як введення правильного пароля, зручний `while`. Обидва цикли можуть вирішувати деякі однакові задачі.


## Приклад із поясненням

```python
for number in range(1, 4):
    print(number)
```

Результат — 1, 2, 3. Верхня межа 4 не включена. У [examples.py](examples.py) є додаткові коментарі до кожного нового кроку.

## Поширені помилки

- `range(5)` закінчується на 4, а не на 5.
- Тіло `for` потребує відступу.
- У `for` зі списком або рядком змінна циклу вже отримує поточний елемент; окремий лічильник не завжди потрібен.
