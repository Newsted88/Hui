# Урок 02. Змінні й типи даних

## Мета уроку

## Перед початком

## Пояснення

Змінна — це назване місце для значення, як підписана коробка. Запис `cups = 2` присвоює числу 2 ім'я `cups`. Знак `=` тут означає «запам'ятай значення праворуч під іменем ліворуч», а не математичне «дорівнює». Python спершу обчислює праву частину, потім зберігає результат.

Ім'я змінної починається з літери або `_`, може містити цифри після першого символу, але не пробіли. Зручно писати `ticket_price`, а не `x`, якщо ім'я підказує зміст. Великі й малі літери відрізняються: `Age` і `age` — різні імена.

Тип значення описує, що з ним можна робити. `int` — ціле число (`3`), `float` — число з дробовою частиною (`3.5`, з крапкою), `str` — текст (`"чай"`), `bool` — одне з двох логічних значень `True` або `False`. Лапки перетворюють запис цифр на текст. `type(value)` показує тип.

Змінній можна надати нове значення: `cups = 2`, потім `cups = 3`. Після другого рядка старе значення під цим ім'ям уже не використовується. Це корисно, коли дані змінюються.


## Приклад із поясненням

```python
cups = 2
print(cups)
cups = 3
print(type(cups))
```

Спочатку видно 2. Після нового присвоєння `cups` містить 3; `type(cups)` показує клас `int`. У [examples.py](examples.py) є додаткові коментарі до кожного нового кроку.

## Поширені помилки

- `=` присвоює значення; перевірку рівності `==` вивчимо пізніше.
- `price = 3,5` записує не десяткове число; у Python потрібна крапка: `3.5`.
- Ім'я `my age` містить пробіл і викликає помилку.
