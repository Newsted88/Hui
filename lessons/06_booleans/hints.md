# Урок 06. Підказки

Читайте наступний рівень лише після власної спроби.

## Вправа 1

1. **Підказка 1:** Згадайте оператор перевірки рівності.
2. **Підказка 2:** Для порівняння потрібні два знаки `=`.
3. **Підказка 3:** Передайте логічний результат у `print()`.

## Вправа 2

1. **Підказка 1:** «Не менший» включає рівність.
2. **Підказка 2:** Згадайте знак `>=`.
3. **Підказка 3:** Порівняйте змінну віку з межею та покажіть результат.

## Вправа 3

1. **Підказка 1:** Потрібні одночасно нижня й верхня межі.
2. **Підказка 2:** Застосуйте `and` до двох окремих порівнянь.
3. **Підказка 3:** Перевірте нижню межу через `>=`, верхню через `<=`, а результати об'єднайте.

## Вправа 4

1. **Підказка 1:** Три результати можна отримати з двох базових перевірок.
2. **Підказка 2:** Парність означає остачу 0 при діленні на 2.
3. **Підказка 3:** Створіть логічні значення для додатності й парності, потім поєднайте їх через `and`.
