# Урок 07. Умови

## Мета уроку

- будувати розгалуження через `if`, `elif`, `else`
- дотримуватися відступів
- читати вкладені умови

## Перед початком

Урок 06: порівняння й логічні значення.

## Пояснення

Умова дозволяє виконати код залежно від результату перевірки. `if умова:` означає «якщо істина, виконай вкладені рядки». Двокрапка починає блок, а однаковий відступ у 4 пробіли позначає рядки цього блоку. Python читає відступи як частину правил мови.

`else:` виконується, коли умова `if` хибна. `elif інша_умова:` додає ще одну перевірку, якщо попередні не спрацювали. У ланцюжку `if`/`elif`/`else` виконується лише перша придатна гілка.

Вкладена умова — це `if` усередині іншої гілки. Вона перевіряється лише тоді, коли Python зайшов у зовнішню гілку. Не додавайте вкладення без потреби: прості умови легше читати.

Для рішень із введенням даних спочатку перетворіть числовий текст на число, потім порівнюйте. Кожну гілку перевіряйте окремим запуском з відповідним значенням.


## Приклад із поясненням

```python
age = 16
if age >= 18:
    print("Доступ дозволено")
else:
    print("Потрібен супровід")
```

Побачите `Потрібен супровід`, бо 16 не менше 18. Відступ показує, який рядок належить кожній гілці. У [examples.py](examples.py) є додаткові коментарі до кожного нового кроку.

## Поширені помилки

- Немає двокрапки після умови.
- Рядки всередині гілки мають різні або відсутні відступи.
- Порядок `elif` впливає на те, яка гілка виконається.
- Два незалежні `if` можуть виконатися обидва; ланцюжок з `elif` обирає одну гілку.
