## Пояснення

`print()` — готова дія Python для показу результату у терміналі. Значення між дужками передається цій дії. `print("Київ")` показує слово, а `print(12)` — число. Кожен виклик зазвичай починає новий рядок результату.

Лапки позначають текст. Можна використовувати подвійні `"..."` або одинарні `'...'`; відкривати й закривати треба однаковими. `"12"` — текст із двох символів, а `12` — число. Ця різниця стане важливою під час обчислень.

Рядок після `#` — коментар. Python його ігнорує. Коментар потрібен, щоб пояснити, чому написано певний код, або залишити примітку. Коментар не замінює інструкцію.

`print()` — приклад функції: готової дії, яку ми викликаємо за іменем. Свої функції ми навчимося створювати в уроці 11. Нині достатньо знати, як її викликати.


## Приклад із поясненням

```python
print("Мені подобається чай")
print(3)
# Це пояснення не буде показано
```

У результаті будуть два рядки: речення й число 3. Коментар не з'явиться. У [examples.py](examples.py) є додаткові коментарі до кожного нового кроку.

## Поширені помилки

- `print(Привіт)` без лапок: Python сприйме слово як ім'я, яке ще не визначено.
- Незакрита лапка або дужка викликає помилку запису.
- `#` усередині лапок — частина тексту, а не початок коментаря.
