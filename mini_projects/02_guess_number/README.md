# Мініпроєкт 2. Вгадай число

**Коли починати:** після уроку 10. Потрібні введення, числа, порівняння, умови й цикли. Списки тут не обов'язкові.

## Завдання

Заздалегідь задайте в коді ціле «секретне» число від 1 до 10. Програма має просити гравця вгадати його, повідомляти «Більше» або «Менше» й повторювати спроби, доки відповідь не збігатиметься. Наприкінці покажіть кількість спроб. Для першої версії припускайте, що гравець вводить цілі числа.

## Кроки

1. Виберіть секретне число і змінну для підрахунку спроб.
2. Запитайте перше припущення та перетворіть його на `int`.
3. Якщо число завелике або замале, покажіть відповідну підказку.
4. Повторюйте введення до правильної відповіді.
5. Покажіть кількість спроб. Перевірте запуск із правильною першою відповіддю, із замалим і завеликим числами.

## Необов'язкові підказки

- Умовою циклу може бути нерівність припущення й секретного числа.
- Лічильник збільшуйте після кожного введення.
- Для двох напрямків підказки зручно використати `if` і `else`.

Пишіть у [starter.py](starter.py). З кореня курсу запускайте `py .\mini_projects\02_guess_number\starter.py`. Не шукайте готовий розв'язок: спершу простежте одну спробу на папері.
