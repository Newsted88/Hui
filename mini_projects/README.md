# Мініпроєкти

Кожен проєкт відкривайте після потрібних уроків:

1. [Знайомство](01_introduction/README.md) — після уроку 03.
2. [Вгадай число](02_guess_number/README.md) — після уроку 10.
3. [Калькулятор](03_calculator/README.md) — після уроку 11.

Пишіть код у відповідному `starter.py`. Він навмисно не містить готового розв'язку. Запускайте з кореня курсу командою `py .\mini_projects\01_introduction\starter.py`, замінюючи шлях для інших проєктів.
