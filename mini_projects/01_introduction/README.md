# Мініпроєкт 1. Знайомство

**Коли починати:** після уроку 03. Ви вже знаєте `print()`, змінні, `input()`, `int()` і `float()`.

## Завдання

Створіть програму, яка запитує ім'я, місто та вік людини, а потім показує коротку картку знайомства. Програма має показати, скільки років людині буде наступного року. Для цієї задачі вводьте вік цілим числом.

## Кроки

1. Запишіть на папері, які питання побачить людина і які відповіді введе.
2. Отримайте ім'я та місто як текст.
3. Отримайте вік і перетворіть його на ціле число.
4. Покажіть картку: ім'я, місто, поточний вік і вік наступного року.
5. Запустіть програму щонайменше двічі з різними даними. Перевірте обчислення вручну.

## Необов'язкові підказки

- `input()` повертає текст навіть для цифр.
- Наступний рік означає додати одиницю до віку.
- Кожен рядок картки можна вивести окремо.
