# Мініпроєкт 3. Калькулятор із функціями

**Коли починати:** після уроку 11. Потрібні функції, параметри, `return`, введення, умови й арифметика.

## Завдання

Створіть калькулятор для двох чисел. Людина вводить два числа та назву дії: додавання, віднімання, множення або ділення. Для кожної дії створіть окрему функцію, яка **повертає** результат. Основний код вибирає потрібну функцію й показує відповідь. Перед діленням на нуль покажіть зрозуміле повідомлення замість помилки.

## Кроки

1. На папері сплануйте чотири функції: їхні назви, два параметри та значення, яке повертається.
2. Напишіть і окремо викличте функцію додавання для перевірки.
3. Додайте три інші функції.
4. Запитайте два числа через `input()` і перетворіть їх на `float`.
5. Запитайте назву дії й виберіть потрібну гілку `if`/`elif`/`else`.
6. Перевірте всі чотири дії, невідому дію та ділення на нуль.

## Необов'язкові підказки

- `return` передає число з функції основному коду; `print()` показує його людині.
- Перевірити друге число на нуль можна перед викликом функції ділення.
- Для невідомої дії залиште останню гілку `else`.
