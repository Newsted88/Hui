# Коротка пам'ятка

Використовуйте лише ті рядки, які вже пояснені на вашому уроці.

| Поняття | Приклад | Що означає |
| --- | --- | --- |
| Виведення | `print("Привіт")` | Показує текст у терміналі |
| Коментар | `# Пояснення` | Python не виконує цей рядок |
| Змінна | `age = 12` | Зберігає значення під іменем |
| Введення | `name = input("Ім'я: ")` | Чекає текст від користувача |
| Перетворення | `int("12")` | Робить із тексту ціле число |
| Порівняння | `age >= 12` | Дає `True` або `False` |
| Умова | `if age >= 12:` | Виконує вкладений код, якщо умова істинна |
| Цикл | `for n in range(3):` | Повторює вкладений код тричі |
| Список | `items = ["чай", "вода"]` | Зберігає кілька значень |
| Функція | `def greet(name):` | Створює дію, яку можна викликати |

Для запуску з кореня курсу: `py .\lessons\00_getting_started\examples.py`. Якщо `py` не працює, використайте `python`.
